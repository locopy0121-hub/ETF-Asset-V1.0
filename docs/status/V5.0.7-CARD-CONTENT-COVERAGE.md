**本版跨頁共用修正：**框架說明顯示於編輯器；原始 JSX 的一般 Text/EditableText 可索引包含巢狀說明文字，文字外觀與靜態標籤寫入現有 layoutTargets，實際畫面使用同一份設定。卡片標題可調整文字及字型；原始行情值／帳務數值唯讀。未掛載之 Modal 不製作假預覽。

**首頁行情牆：**新增昨收、來源成交量、來源時間、股數、含費均價、權重、已領股息、已實現損益、純價差損益及含息總損益十欄，預設隱藏，保留原有持股/自選排列與既有儲存設定。行情不存在顯示「待取得」，不製造零值。

**獲利試算：**指定目標賣價及目標淨獲利，依 Canonical 模擬買進及全數出清（含手續費及稅）反推最低整股／零股加碼股數與現金需求；不修改正式 Ledger。未驗證行情不得推算。

**仍未完成／待驗證：**所有由不透明自訂子元件內部建立的說明文字，無法僅藉由父層 JSX 樹自動列舉；部分需於獨立細節視窗維護工程師選取。手機點擊、樣式持久化重開及長列表／圖表邊界須手動驗收，故 **不聲稱全頁 RESULT/RELEASE PASS**。
