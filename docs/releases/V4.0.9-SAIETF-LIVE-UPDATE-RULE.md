# TF Asset V4.0.9｜SaiETF LIVE 更新定律

基底：TF Asset V4.0.8（原 TF Asset V3.2.49 主線），Android 40009。SaiETF 對照版本 `locopy0121-hub/Saietf_V1.0.1` main `8a22979cde7c0da685afb77be80cea980df1b159`。

## 更新與價格來源

- App 啟動、持股變動與回前景立即查詢；台北平日 09:00–13:30:00 每秒檢查；其他時間在前景每 30 秒檢查，背景暫停輪詢與 Fugle WebSocket，回前景恢復訂閱。
- Fugle WebSocket trades 是具備本 App Fugle API Key 時的主要即時來源。只在有效新鮮串流未覆蓋標的時使用 TWSE MIS，再使用 Yahoo；官方 MIS 最短 1 秒、Yahoo 最短 15 秒，429／403／5xx 遵循原生 circuit breaker。網路來源不保證每秒回傳新成交價。
- Memory Hot Store 報價變更直接推送 React Native；每秒快照讀取用於啟動、異常恢復與持久化圖表。每個新 tick 更新資料版本並重投影既有 canonical ledger 的市值／持有損益。不改動財務核心費稅與交易紀錄。
- Fugle 訂閱只取正持有的代號，完整賣出的歷史標的不留在清單；異動立即送原生串流，不等待慢 HTTP 查詢。AI 單檔查價不替換持股訂閱。
- 同盤／來源時間／試用報價／過期資料仍由 SaiETF 仲裁；盤中缺任一持股有效報價時總值不冒充完整估值，損益也不以舊盤價補足。
- TF Asset 的自訂盤中／盤後時間、開關、60 秒盤後與停止全部自動更新規則已從執行路徑及設定介面移除。舊 JSON 僅遷移 catalog 與最近來源時間，不再載入舊排程。

## 驗收

1. 盤中 Fugle 顯示 LIVE 且有新 tick 時，不等下一次 HTTP 批次或一秒計時器，首頁與持股市值及損益同步變化；沒有報價時仍待核對。
2. 盤中新增／賣光持股、AI 查詢非持股時，持股 Fugle 訂閱保持正確。
3. 背景暫停、回前景立即恢復；非盤中 30 秒；確認 13:30:01 已切非盤中。
4. 診斷來源時間／LIVE／DELAYED／STALE／缺價覆蓋，與 SaiETF 同代號比較；Fugle Key 在 TF Asset 獨立設定，兩個 App 不共用 Android 安全存放區。
