# TF Asset V4.0.10｜SaiETF 全局事件行情與損益

## 修正

- 盤中持股行情由 SaiETF 原生 Fugle 訂閱的有效成交事件優先驅動；來源異常時由 SaiETF 行情中心管理備援。移除 JS 的 1 秒讀取、盤中 1 秒／盤後 30 秒網路排程。
- 同一市場快照與 canonical ledger 投影首頁、庫存、Widget、浮動 Monitor 與 Mini；行情版本變化立刻推進財務估值時鐘。價格來源有效期到達時按到期點重繪，不再每 30 秒重算。
- Widget／Monitor／Mini 的手動刷新經原生事件交付前景 App，不再輪詢請求旗標；App 不在執行時 Widget 明示等待同步與上次來源時間。
- 盤中最後成交超過 30 秒且未有新成交時，損益仍以最後可核實成交計算，原生畫面標示「延遲」；來源時間跨交易日或有效期限屆滿後不宣稱完整盤中估值。
- 版本為 4.0.10，Android versionCode 40010。CI 的 `qa-apk` 工作在 `v4.0.*` 分支推送時產生 QA APK、SHA256 與 badging。

## 驗證

- `npm run typecheck`
- `npm run test:v4_0_10`
- `git diff --check`
- Android 原生編譯及 QA APK 由 GitHub Actions `qa-apk` 工作驗證。

## 使用範圍

當 App 可執行且 Fugle 提供有效 Tick 時即時同步。Android 對已關閉 App 的桌面 Widget 有背景限制，該情況顯示最後同步時間與等待狀態；不得視為持續 LIVE。
