# TF Asset V4.0.4：估值交易日與原生顯示有效期限

## 問題與修正

原先估值投影只驗證價格正數、來源時間存在與 quality，盤中前一交易日行情仍可被認為有效。原生顯示端還會從 SQLite 覆蓋 App 已清空的價格。

本版採用來源時間與臺北交易日驗證：平日 09:00–13:30 僅接受同日 trade / backup_realtime，拒絕 STALE、OFFLINE、未解析證券、未來超過兩分鐘與超過七日的快取；同日 DELAYED 最後成交保留。盤外可使用七日內的成交／收盤參考，UI 明確顯示「盤外參考價」。退休的 bid_ask 不可核實估值。sessionDate 必須與來源時間一致。

FinanceProvider 每 30 秒及回到前景時重算有效性。估值投影附帶下一個平日開盤／七日期限中較早的有效期限。Widget、Monitor 使用同一原生 presentation adapter：必須通過 App 有效期限、價格與來源時間匹配；失效、未解析、價格版本不同時清空目前價格及估值數據，禁止從快取復活無效價格。浮窗以原生 Handler 到期更新並在服務銷毀時清理；小工具以 AlarmManager 到期重繪並在移除時取消排程。

## 不變條件

ETF 帳務核心、買賣稅費、已實現損益、股息入帳規則及原始帳本不變。無有效報價時的帳本價格只供既有 canonical 核心維持持倉覆蓋，不作已核實行情展示。

## 界線與後續

平日盤中判定尚未接入交易所休市日曆；這是稽核清單另列的工作。Android 未授予精確鬧鐘權限時，小工具使用系統允許的非精確 idle alarm；作業系統可延後派送，尚不能宣稱所有裝置在期限到達的同一毫秒重繪。本次 QA APK／CI 不等同實體裝置端到端行情與畫面驗證。其餘股票帳務邊界、股息狀態、FrameCard 顏色、排版及備份修復仍按稽核清單分階段處理。
