# TF Asset V4.0.13 — ETF 成分股資訊

基底：V4.0.12 / d4f8a99e39d79339b23fa16f0944da31994bba65。Android versionCode：40013。

## App 行為

持股資訊下方新增 ETF 成分股卡片。按權重降冪顯示中文名稱、代號與百分比，預設前十大，可展開所有已取得成分。顯示來源與原始資料日期；部分揭露、PCF 估算及更新失敗均明確標示。

新增正股數的 ETF 持股即自動下載，不必開啟詳情頁。共享記憶體快取供卡片讀取，AsyncStorage 保存已下載快照。股票行情 tick 不觸發下載。相同代號請求合併，失敗自動重試有五分鐘冷卻；手動更新可重試。星期一至五台北時間 08:30、13:20、14:30 更新，回到前景補做錯過的檢查。來源沒有發布 webhook，因此此版依檢查時點查詢，而非聲稱即時收到官方通知。交易所休假日可取得上次公布資料，但不偽造新的資料日期。

更新失敗不清空舊資料；同日部分資料不能覆蓋完整快照。ETF 權重不強制正規化成 100%，保留現金、期貨等非股票部位差額。既有金融核心與 LIVE 行情中心未修改。

## 已驗證來源

- 元大官方持股權重：https://www.yuantaetfs.com/product/detail/0050/ratio 。頁面 SSR 只顯示五檔；解析完整 Nuxt StockWeights。只解碼白名單資料 token，不執行外部 JavaScript。
- MoneyDJ 完整持股：https://www.moneydj.com/ETF/X/Basic/Basic0007B.xdjhtm?etfid=006208.TW 。僅讀取持股明細表及其資料日期，不誤用區域／產業分布日期。完整來源不可用時讀摘要頁並標為部分資料。未揭露股票部位的 ETF 保留無資料狀態。
- Fugle 官方文件：https://developer.fugle.tw/docs/data/http-api/ownership/etf-holdings/ 。確有此端點，且限定開發者／進階方案；未因 API Key 已設定就啟用可能付費的功能。
- 富邦官方文件：https://www.fbs.com.tw/TradeAPI/en/docs/market-data/http-api/ownership/etf-holdings/ 。需要帳戶／SDK 資格，此版不依賴登入。

## 可部署的後端

在既有 server 加入 PostgreSQL migration `004_etf_holdings.sql`：etfs、etf_holding_snapshots、etf_holdings。每次更新在單一 transaction 中替換成分，使用 ETF advisory lock 防止交錯；保留不同日期歷史。Redis 儲存公開成分快取，寫入 commit 後失效。

- GET `/api/v1/etf/:symbol/holdings`：唯讀快取／DB，404 表示尚無資料，503 表示服務不可用。
- POST `/api/v1/etf/:symbol/track`：登記公開 ETF 代號；已有資料直接回傳，缺資料才進行合併抓取。需抓取新資料時每個 IP 每分鐘上限 20 次（快取讀取不占上游額度），追蹤上限 300 檔。未傳送使用者帳務、股數或成本。
- 三個台北時間工作日排程；服務重啟從 etfs 恢復已追蹤代號。
- 設定「行情與資料中心」可填 HTTPS 基底網址。未部署／未設定資料中心時，App 使用本機事件取得公開資料；已設定後端失效时，保留快取，不讓所有客戶端向上游扇出爬取。

此提交提供後端程式與 schema，沒有宣稱已部署一台可運行的伺服器。不能保證 App 被 Android 終止後仍會執行 JS 排程；持續背景抓取需部署後端。

## PCF Python 範例

`server/scripts/parse_etf_pcf.py` 接受已下載並完成來源欄位對照的 PCF CSV 與同日期收盤價 CSV，輸出標準 JSON。必須提供核實過的官方來源 URL；缺收盤價、價格日期不同、重複股票、非法數值或未處理現金替代均拒絕計算。PCF 是申購買回籃子，不當作實際基金持股；輸出 `basis=pcf_estimated`。採用現有 Node/Express/PostgreSQL/Redis 與 App Context，避免額外建立第二套 Zustand／React Query 狀態來源。
