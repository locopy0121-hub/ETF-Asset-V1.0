## Explicit boundaries

Filtering is cosmetic content filtering plus known ad navigation rejection, not a universal Android resource-network blocker. Unknown ad markup can remain. Website-specific darkening in the supplied TVBS screenshot has not been reproduced on the user's phone; isolated light reader content supplies a readable alternative, not proof of that site's sole cause. Reader never unlocks restricted/hidden content. If a body cannot be identified safely, original page remains usable.

The design preview's prices were fictional. Production views use existing market data, retain true source timestamps and subscription ownership, and do not create a new price source or update interval. Original phone upgrade latency, true Fugle reception, site layout and reading interactions still need device acceptance. QA build success is not RELEASE PASS.
