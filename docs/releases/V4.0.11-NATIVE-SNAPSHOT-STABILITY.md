# TF Asset V4.0.11 — 行情牆 / Mini 快照穩定性

起點：V4.0.10，commit e297224fa89d60888b57353398a9575e86f86015。
備份：backup-v4.0.10-pre-v4.0.11。

## 根因與修正

原生 Monitor、Mini、Widget 用 canonical App 快照再對照非同步 SQLite 報價。
較新 Tick 或持久化延遲導致價格 / 時間戳不相等，presentation 把有效價格清空。
此外，單一缺少行情會讓全部持股損益被清空。

- 原生畫面只投影同一份 canonical 快照，不再讀 SQLite 作顯示 Gate，也不在原生重新算金融損益。
- 快照携帶 quoteStatus / marketQuality / source timestamp / valuation deadline；保持過期、盤中跨日、STALE、OFFLINE、不可用行情的拒絕規則。
- 逐檔保留已驗證的價格、市值、損益及報酬率。組合未完整時總資產 / 總損益仍不宣稱完整。
- 同日最後成交超過 30 秒標示延遲，等待新 Tick 時不因 SQLite 寫入順序閃空。
- Monitor / Mini / Widget 更新時間轉為 Asia/Taipei，修正 12:55 顯示成 04:55。
- API Key、Fugle 訂閱、帳務核心及使用者版面設定保持既有行為。
