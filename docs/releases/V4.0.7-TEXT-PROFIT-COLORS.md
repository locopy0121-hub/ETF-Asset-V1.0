# TF Asset V4.0.7 文字損益色修護

版本 4.0.7 / 40007，延續 V4.0.6。修護使用者回報「整體文字損益色設定無法正確套用」，對應檢整 P1-02 文字狀態與 P1-03 文字覆寫接線。

## 根因與修護

- PageEditorStack 一般 Text 目標缺金融狀態：現在遞迴繼承所屬 FrameCard 的 canonical 金融 tone，不從文字內容猜帳務數值，非金融框架保持中性。
- DashboardProfitDetail 標題未提供對應列 tone；Overview 標題、金額、前綴與說明未跟隨總損益。現在對應來源傳入；昨日／今日標題各自對應昨日／今日數值。
- 直接設定預覽 DashboardEditableText 原本忽略 profitToneOverride，現在依明確覆寫或真實 tone 選色。
- MetricTile、ValueRow、dashboard KPI 與原生 metric 狀態契約補 neutral；首頁、庫存、詳情及預覽的零值與估值不足不再用 >=0 判盈利。歷史已實現與股息使用其已知帳本數值，不被即時行情缺失抹除。
- quote-card 維護目標缺 tone：補入該張行情卡的日漲跌，可信行情與已知前收皆不足時中性；欄位 PnL／ROI 使用各自既有損益來源。
- 個別卡片文字覆寫先解析一次，再傳實際欄位；關閉主要／次要再次判色，防止固定色或手動 tone 被底層覆蓋。僅字級等非色彩覆寫仍保留原欄位判色。
- 精簡三欄卡損益沿用 pnl 欄位設定，不強制啟用損益色；名稱／代號 header 不再跳過主要／次要文字損益色。行情卡文字、標籤與連動背景均檢查 quoteVerified／前收可用性。
- 保留全域紅漲綠跌／綠漲紅跌、自訂中性色、各文字固定色與透明度；不改帳務數字、版型、持股欄位與原 ETF 計算。

## 驗證

- 修改前中性色 metric 渲染斷言失敗；新增實際執行測試亦可透過 `TF_TEXT_BASELINE=1` 使用 V4.0.6 原始碼重現一般文字、標題、直接覆寫、quote-card、header 與精簡卡錯誤。
- `scripts/v4_0_7-text-profit-render.test.cjs` 執行實際 MetricTile、DashboardEditableText、DashboardProfitDetail、PageEditorStack decorator、HoldingQuoteCollection／Module；RN host／Inspector 儲存與幾何替身僅隔離外部環境。
- 驗證 gain/loss/neutral × 兩模式、標題／數值／說明、遞迴文字、直接與卡片覆寫、固定色、micro 欄位固定色、待取得中性、主次文字開關與卡片覆寫優先。舊碼 red、新碼 green。
- TypeScript、完整 test:v4_0_7、controls smoke/runtime、AI holdings、股息月曆、system colors 與 QA identity 全部通過；審查抓出的缺漏已補測修護並復驗。
- 舊 v3_1_16 檢查鎖死 HoldingQuoteCollection 整檔 UI hash；更新已授權視覺接線基準，補註新增執行測試。其餘 editor、floating preview 與 canonicalLedger hash 鎖定保持。
- canonicalLedger.ts、etfCalculators.ts、CORE_LOCK.md 未修改。GitHub Actions #3209 品質、後端整合與 QA APK 全部成功。

## 裝置驗收

1. 全域模式與自訂三色切換，首頁／庫存／詳情損益文字即時更新；零值中性，資料待核對不冒充盈利。
2. 一般文字、儀表板標題／數值／說明、NT$ 前綴：開損益色對應金融狀態，關閉保留固定色，透明度不變。
3. 行情牆主要與次要文字、名稱／代號、PnL 欄位、精簡三欄卡分別驗證；個別卡片固定色及手動狀態不可被次要旗標重新覆寫。
4. 設定預覽／維護工作台切換手動損益狀態、儲存、重啟，確認實際畫面與已保存偏好一致。
5. 小螢幕、動態字體、深淺色與字體對比需真機確認。Host 執行測試不等同像素驗收。

本版不宣告全部檢整完成：P0-02 股票／ETF 帳務邊界、P1-03 其他主題／模板與原生外觀作用範圍、其他完整預覽／工具適配仍在清單。
