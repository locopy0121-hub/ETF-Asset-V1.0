# TF Asset V3.2.17｜盤中 1 秒行情排程與跨時段自動啟動

## 目標
行情中心在 App 前景使用期間持續依市場排程運作，不依賴進入設定頁或手動按「立即更新行情」。

## 本版修正
- App hydration 完成後立即取得行情；App 回到前景立即強制刷新。
- 盤中 09:00–13:30 預設更新頻率由 5 秒調整為 **1 秒**，設定最低值維持 1 秒。
- 排程器改為每秒 heartbeat 重新判斷台北市場 phase，避免 App 在盤前開啟並跨過 09:00 時仍停留在 offline、沒有啟動盤中行情。
- heartbeat 只負責檢查時段；真正網路抓取仍依各 phase 的 refreshSeconds 節流，不會把盤後設定誤變成每秒網路請求。
- 行情 phase 狀態僅在真正切換時更新，降低不必要 React 重繪。
- 手動「立即更新行情」保留作為強制刷新／診斷入口，不再是自動行情更新的必要條件。

## 資料架構
TWSE／官方來源 → 統一行情資料中心（SQLite）→ 全 App Consumer。各畫面讀取統一行情中心，不互相把首頁資料當來源。

## 不變核心
交易手續費、證交稅、Math.floor、最低手續費與 Portfolio 加總規則未修改。
