# V4.0.56 — Ten holding Monitor models and quote fields

User authorizes autonomous planning of approximately ten floating Monitor models, referring to the supplied broker holding quote cards, with stronger selectable items such as volume and previous close. Baseline is the synchronized V4.0.55 (c5e6132ac858bb3855a9048e601788ba38c0c39c); backup branch backup-v4.0.55-pre-monitor-models-20261014.

Ten presets: broker two-column, three-column overview, detailed single-column, large quote, compact holdings, cumulative volume, previous-close comparison, cost comparison, profit ranking and allocation. Presets reuse the existing market-wall renderer with different columns, typography, fields and sort. Existing twelve legacy templates remain available. Applying a preset preserves symbol selection, window position/size, mini configuration and custom field labels/colors. The normal field visibility/order/fonts and preset style are deliberately replaced.

Monitor-only field contract extends the holding wall contract without changing shared holding-card defaults. Adds cumulative source volume, previous close and quote status to normal and mini options, plus existing shares, cost, weight, return and time in the wall detail rows. Detail rows wrap into two cells per row (three for a single-column model); name and symbol share the heading, price is prominent and change fields stack beside it. Missing values show --; zero volume remains 0. Volume shows the source number without an inferred unit conversion. Fugle stock trades documentation defines volume as total volume: https://developer.fugle.tw/docs/data/websocket-api/market-data-channels/trades/ .

Snapshot adds display-only source volume through the existing shared adapter, for foreground and background consumers alike. No extra requests, subscriptions, polling, triggers or finance formula changes. V55 latest-render queue remains intact. Invalid native presentation clears volume with unavailable price metadata.

Validation: real preset/snapshot tests, actual Settings provider normalization and panel button/preview tests, compiled Kotlin production formatter/section tests, null-last numeric sorting, inherited aggregate gates, TypeScript and GitHub native APK build. Device visual and continuous-update acceptance remain pending; no emulator or phone connected.
