## 驗收清單

| 項目 | 實作／驗證 | 自動化 | 真機 |
|---|---|---|---|
| 每張卡片維持單欄尺寸 | normalLayout.width 是單欄基準，扣除外框左右 padding 後得到固定 cardWidth。Native 建立／更新／Normal-Mini 切換共用視窗幾何；移除平均權重、依欄數縮字及內部分欄差異 | 實際預覽 1/2/3/5/12 欄的卡寬、全部文字樣式與欄位布局一致；編譯 Kotlin 幾何 | 待驗收 |
| 視窗隨欄數展開、可取用超出畫面卡片 | 寬度 = 左右外距 + N × 單卡寬 + (N−1) × 間距；視窗上限為螢幕寬度，卡片不縮小，橫向捲動；原有縱向捲動保留，行情重繪保留捲動位置；最後列不足不放大 | Kotlin 單欄/多欄/窄螢幕/不足列/極大值幾何，預覽固定寬卡與橫向入口 | 橫縱向手勢、拖曳位置、螢幕邊界與縮小／還原待驗收 |
| 可自填並保留欄數 | 數字輸入、完成送出、離開欄位、加減；空值／負值／小數／溢位不寫入。支援 Android 正整數範圍 1～2147483647，非 1～4 選項限制；只建立實際存在標的，不建立大量空格 | 實際控制項提交／錯誤／加減；實際設定 normalize 的 5/12/100/Int.MAX_VALUE 保存載入 | 鍵盤、重新啟動保存待驗收 |

欄數多於標的時，只顯示現有卡片；不配置空白占位物件。Native 測量尺寸另有 24-bit 像素安全界限，避免整數溢位。大欄數不會把每張卡片縮窄。
