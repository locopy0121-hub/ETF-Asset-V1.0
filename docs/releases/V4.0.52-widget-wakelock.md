# V4.0.52 — Widget intraday startup permission

V4.0.51 shipped without android.permission.WAKE_LOCK. React Native 0.86.3 HeadlessJsTaskService starts by acquiring a partial wake lock. The trading-session Widget service enters this code only when a Widget is installed and the schedule permits startup. The user confirmed removing the Widget restores App launch. Device crash stack remains unavailable.
