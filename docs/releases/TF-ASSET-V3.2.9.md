# TF Asset V3.2.9

日期：2026-09-29

## 目標

修正首頁「今日損益」把帳務總損益差額當成持股市值變動的口徑錯誤，並把每日損益歷史改成自第一筆交易日起，以當日實際持股和證券中心正式歷史收盤資料重建。

## 本版實裝

- 每日市值損益：`當日持股市值 - 前日持股市值 - 買賣本金流`。
- 買進／賣出本金只改變部位，不再被當成市場獲利或虧損。
- TWSE 與 TPEx 個股月歷史資料共用同一歷史抓取層，最長支援 30 年。
- 依 Ledger 逐交易日重播當時持股，產生自第一筆交易至今的正式每日 Portfolio Snapshot。
- 正式收盤紀錄可取代舊 live/previous-close 暫算，之後不被盤中行情覆寫。
- 每日明細新增前日持股市值、當日持股市值、買賣本金流與帳務調整，明確區分市場變動和 Finance Core 總損益。
- 首頁移除「前日＋今日＝總損益」的混合口徑符號，改成三項獨立資訊。
- Immutable Finance Core 不修改。
