# TF Asset V4.0.6 框架損益色修護

4.0.6 / 40006，延續 V4.0.5，修護檢整 P1-01。原 TF Asset V3.2.49 主體、帳務數字與框架排版保留。

## 根因與接線

FrameCard 原先 12 個 linkedColor 入口固定傳 neutral，開啟損益色仍只顯示中性。新增金融 tone 輸入，非金融框架預設 neutral，各原開關保持獨立；背景、標題、邊框、漸層端點、中點、遮罩、陰影、Glow、外光暈、閃爍與邊框漸層均依同一實際狀態選色。

| 實際框架 | 金融來源 |
|---|---|
| 首頁資產總覽／損益分析／損益明細／持股行情模塊 | canonical totalPriceUnrealizedProfit（持股純价差總損益） |
| 庫存持股分析儀表板 | canonical totalPnl（該摘要顯示的含息總損益） |
| 庫存持股檢視 | canonical totalPriceUnrealizedProfit |
| 單一持股損益拆解 | pricePnl |
| 單一持股股息 | cumulativeDividend |
| 非金融框架 | neutral |

零、非有限值及估值不完整時用中性；個別持股依 quoteVerified 檢查。沒有將今日漲跌代替總損益，也不修改公式或金額。Settings 既有實際頁預覽（首頁金融框架、庫存持股檢視）共用 portfolioFrameTone；尚無實際內容預覽的其他框架不宣告完成 P1-11。

損益色只在相應開關啟用時生效；關閉保留原固定色。全域紅漲綠跌／綠漲紅跌模式、透明度與各效果既有數值保留。PageEditorStack cloneElement 保留 tone，維護草稿不覆寫金融來源。

## 裝置驗收

1. 同一持股組合盈轉虧，首頁總資產框架色依總持股損益變化；今日漲跌相反時不改判斷來源。
2. 全域切換兩模式，開啟的框架色彩效果立即切換；關閉的固定色保持。
3. 背景、標題、边框、漸層、遮罩、陰影、Glow、外光暈與閃爍分別啟用／關閉，透明度保持原值。
4. 零損益及估值待核對時中性，不冒充盈利；資料恢復後重新判色。
5. 設定既有實際頁預覽與相同金融框架一致，維護工作台儲存後重啟仍保留開關／固定色。
6. 確認小螢幕、動態字體、深淺色，原框架順序／尺寸／内容仍保持。
