# TF Asset V4.0.12 — 盤後行情穩定性

## 問題

收盤後，Fugle 當日最後成交因超過 30 秒而進入延遲狀態。手動更新、回到前景或重開 App 時，MarketDataCenter 會再次查詢 TWSE／Yahoo；既有仲裁先比較時間，因此時間較晚的低優先備援行情可能取代已驗證的 Fugle／TWSE 成交，造成行情牆、Mini 與 Widget 的價格及損益跳動。

## 核准設計

1. 台北時間 13:30 起視為盤後，與 TypeScript 估值層一致。
2. 盤後保留當日已驗證的 Fugle／TWSE 成交；Yahoo 備援不能只憑較晚時間覆蓋可信成交。
3. 已帶有收盤旗標的可信快照不重抓；其餘代號仍可接受同級可信來源的較新正式成交。
4. 任一代號缺值只影響該列；其他列繼續顯示，資產總計仍遵循完整估值門檻。
5. 保留原始來源時間、七日離線上限、跨交易日失效與下一交易時段重新驗證。

## 驗收

- Fugle 13:30 收盤成交不會被較晚的 Yahoo 備援價取代。
- 13:29:59 發出的請求即使跨過收盤才返回，也不能覆蓋期間收到的 Fugle 收盤成交。
- 盤後完整快照不再發出不必要的 fallback 請求。
- 缺值代號仍能個別補抓，且不改動已覆蓋代號。
- Android 與 TypeScript 在 13:30:00 同時進入盤後。
- 冷啟動載入的持久快照保持原來源與時間，可供行情牆、Mini、Widget 共用。
