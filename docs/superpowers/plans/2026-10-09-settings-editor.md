# V4.0.15 設定編輯接線

基準：V4.0.14 / 413980a；GitHub 父提交 451a794。使用者已指示實作與 GitHub 建置，由本工作階段直接執行。

1. 一般設定新增完整框架清單，保留已具備真實預覽的模組；不以空白卡假報內容預覽完成。隱藏框架亦可選回並重新顯示。
2. 建立正式畫面的 FrameEditingContext 與共用原生文字／控制項適配。靜態模板 ID 不含財務原值，動態文字只能改外觀。既有 adapters 保留。
3. 控制中心十分類使用 PageEditorStack，補頁首與設定入口。專業圖表使用已註冊獨立框架，讀取保存圖表預設。
4. 全域顯示函式 formatAmount / formatPercent / formatDate；正式帳務數值保持唯讀，價格與股數精度不套金額四捨五入。字體比例只作用顯示層。
5. 為未適配的主要清單、表單、成分股、配置圖文字與按鈕接入共用適配；業務彈窗另接獨立編輯作用域。
6. 行為測試：格式零／負數／小數／千分位，動態資料不可文字覆寫，輸入值不變，取消與重啟配置維持，所有框架可選與隱藏恢復。
7. 完整繼承測試、TypeScript、Expo、Native 行情 Gate；升版 4.0.15 / 40015，GitHub 建置並驗證 APK 身分、簽署與 SHA256。

限制：繪圖引擎內部坐標／線條、系統 Alert、媒體 WebView 正文不冒充一般文字目標；全頁真機點選仍需設備驗收。每项交付狀態另記錄，73 組盤點不以宣告矩陣一次標成全部通過。
