# V1.0.8 Monitor Display Upgrade

- Mini remains a dedicated list renderer.
- Mini row count is unlimited; no take/slice/subList row cap is permitted.
- Mini height shrinks to content up to the configured maximum height.
- When content exceeds the visible height, the Native overlay uses internal vertical scrolling.
- Normal Monitor themes now include 行情牆、漲跌熱圖、損益牆、資產權重牆、跑馬行情、純文字終端.
- Theme controls layout/presentation only; Snapshot data source and field contracts remain shared.
- Normal / Mini layouts remain physically isolated.
- Immutable finance core is unchanged.
- TF Asset project boundary only; no V5/360 import.
