## 分階段技能落地
本版建立完整技能目錄及工具擴展合約。框架文字、色彩、邊框、尺寸／排列、顯示、陰影、新增基礎元件與取消／套用等首批工具接通；圖表、複雜手勢、Widget 原生等專業技能可以從目錄查看，尚未接入的工具**標示待實作且不得宣稱已完成**。後續各元件專屬適配需逐一有 UI、Runtime、測試及必要真機證據。

## 資料與交易規則
- 元件**定義**全 App 唯一共享；各頁、各框架的元件**實例**獨立配置與儲存。
- App 設定下的工程師永遠隸屬所在頁面設定；全局開關只允許／禁止現場呼叫。
- 活動扳手在使用者選定當前對象時直接確立 A，不得再次要求選 A。
- 當次編輯草稿僅存在記憶體；上方原場景直接顯示，取消立即丟棄，套用才寫入 AsyncStorage。
- 預設只改當前實例。共享模板修改必須另行明示；沒有資料源時禁止假造圖表。
- 不操作任何 Finance Core 檔案、既有帳務儲存 schema 或 Native Widget 程式。

## GO Gate
1. 備份 ref 實存，身份與規則閱讀完成。
2. 每項：修改 → 對應自動驗證 → 功能完整性檢查；FAIL 原地修復。
3. PR QA Action 完成後每 15 秒查狀態，失敗查看實際 job log。
4. Artifact 必須驗證 APK 實體、ZIP 完整、SHA-256、badging、版本與下載。
5. 自動化 PASS ≠ 真機 PASS；未驗證保留 QA 狀態；回報本輪 6 項完成與未完成數。
