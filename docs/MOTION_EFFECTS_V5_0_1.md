# TF Asset V5.0.1 動畫擴充說明

更新日期：2026-10-19
範圍：同一 V5.0.1 版號之程式增補；原版號、套件識別碼、既有設定主頁均未更動。

## 動畫庫
共 42 種選項，含 5 種基本、5 種進場、4 種退場、5 種強調、6 種數值、6 種視覺、5 種互動、6 種行情動效。
沿用既有 5 種動畫 ID，以確保舊備份能正確載入。完整清單位於 `src/domain/displayItemContract.ts`。

## 已串接
- 持股行情牆：標題 A 與數值 B 欄位各自設定。變動時觸發、首次顯示、漲跌觸發、點擊、長按與選用循環。
- 通用 React Native 動畫渲染：原生驅動的透明度與 transform；數字插補使用限頻 JS 文字更新；動畫被新行情取代時會取消舊動畫。
- 設定彈窗：按類別選效果、動畫時間 100–1200ms、強度 0–100%、循環開關、模擬行情預覽。框架可獨立選動畫。
- Mini 與 Widget 的編輯器共用上述類別與參數設定；原有四種全域系統特效仍維持相容。
- 行情趨勢圖：選擇「趨勢線動態繪製」時，持股微型圖隨數據變更播放延伸效果。
- 閒置、背景與無障礙降低動態效果時避免非必要播放；預設全部為「無」。

## 平台差異與限制
- Android 桌面 Widget 為 RemoteViews，**不能使用 React Native 的 Animated 引擎**。本次提供一致的編輯資料契約，但原生桌面僅能依各 Widget 現有能力顯示可用的更新/視覺狀態；不宣稱 42 種動效皆能在桌面 Widget 播放。
- 「成交量脈衝」需要具有成交量資料綁定的數值項目才具備正確行情意義。不存在成交量欄位時不會虛構數值。
- 「拖曳吸附」提供被選項目的拖動與原位回彈視覺，不更動卡片排序/尺寸，避免與既有工程師模式衝突。
- React Native 非線性漸層需要額外繪圖引擎。本次流光/漸層使用低負擔的疊層近似效果。
- 個別行情變動動畫不代表資料來源重新輪詢；所有動效僅消費已取得之行情結果。
