# TF Asset V4.0.15 / Build 40015

本版承接 V4.0.14 的 App 內新聞 WebView，補齊主要設定編輯接線。原始財務核心、行情仲裁與 SaiETF 原生網路入口未修改。

| 區域 | 本版實作 |
|---|---|
| 一般頁面設定 | 全部已註冊框架可選，包含隱藏框架；有真實預覽者沿用，其他框架明示須到實際頁編輯內容 |
| 控制中心 | 頁首與十分類納入 PageEditorStack；原有業務設定及操作保留 |
| 專業圖表 | 八個獨立框架與已保存圖表預設；代號與名称唯讀 |
| 主要清單、表單、按鈕 | 共用原生 Text/TextInput/Pressable 適配，靜態標籤可改，動態值與表單輸入不可改寫 |
| 業務視窗 | 新聞、購買損益、交易明細／日期／確認、持股試算、股息新增／日期，各有独立作用域及 Modal 工作台 |
| 全域 | 底部導覽列、已展開浮動 AI 接入獨立框架與即時 draft |
| 顯示格式 | 主要畫面金額、個股百分比、新聞與交易日期接入設定；原生文字字體比例接入顯示層，股數保留精度 |

尚待後續與設備驗收：一般設定中尚無內容預覽的框架；圖表引擎內部 SVG 線條與坐標；系統 Alert；媒體 WebView 內部 DOM；原生 Widget/Monitor/Mini 字體比例；浮動 AI 收合／最小化元件；尚未轉換的日期與百分比小欄位。73 組盤點不能因共用 adapter 加入而全部標為驗收完成。

本機驗證已通過：98 個繼承與新增測試命令、V4.0.15 格式／真實 TextInput 與 InspectableTarget／編輯 scope 行為測試、TypeScript。Expo 套件比對在本機離線模式驗證；線上比對由 GitHub CI 執行。APK 是否成功以 GitHub 實際建置與產物身分檢驗為準。未連接 Android 裝置，未宣稱全頁真機點選通過。
