# TF Asset V4.0.17 — 持股檢視「實際頁面／預覽一致」修復

基底 V4.0.16（受保護設定主頁原樣保留）。先前 PageLayoutToolWorkbench 的 holding-view 無論目前 portfolioViewMode 是清單還是行情牆，都硬套 HoldingQuoteCollection，導致真實表格與深色卡片預覽不符。

- 清單狀態使用正式 PortfolioQuickBar + PortfolioHoldingTable，欄寬／列高／欄位／標籤使用同一 portfolioList 草稿設定；fallback 使用 PortfolioSafeList。
- 行情牆狀態使用正式 HoldingQuoteCollection，保留原本卡片／欄位／Mini 圖表選取功能，並預覽排列選項。
- 清單狀態的編輯工具是 PortfolioListEditor，不錯誤地提供行情卡片與 Mini 圖表編輯工具。
- 第一鍵標籤與本地 listFallback 狀態由 PortfolioScreen 傳給預覽；預覽中的業務導航鍵只展示，不誤觸發真實行情／帳務動作。
- 同一批持股行情快照傳入預覽，依草稿排序；金融來源、估值定義與資料內容不改。
- 「控制中心／系統設定」保持 V4.0.14 保護基準，僅 VERSION／BUILD 常數遞增。既有 Git blob SHA 保護測試保留。
- CI、APK 成功不代表已經通過手機內點選驗收；需以同一裝置實際對照清單、行情牆及編輯取消／套用。
