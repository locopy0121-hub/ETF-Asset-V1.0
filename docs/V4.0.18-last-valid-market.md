## 根因
JS 與原生只依平日時段判斷開市，10/9 國慶补假被判定盤中；來源日期不等於今天、STALE/OFFLINE 或七日期限導致有效歷史價格被拒絕。快照轉換亦僅回傳 incoming rows，空回應可能清除已知行情。

## 驗收
新增 JS 行為測試覆盖 10/9、開盤無 tick、長假、無效與未来來源時間、空快照、較舊與較新價格、年度日曆載入；Kotlin 測試覆盖官方日期解析、正常開始交易日不誤判、休市原生展示。更新與新需求衝突的舊「過期即清空」測試，保留無來源／無價格拒絕與帳務核心 gate。

本機 tsx CLI IPC 不可用，以 node --import tsx 執行同一套 script graph；GitHub 使用既有 npm 測試入口。

限制：年度 API 與內建公告表不代表即時天災停市公告監控。未收到相關公告時不以零 tick 推斷臨時休市；仍保留最後行情並標示來源時間。尚無任何有效行情的標的仍顯示待取得，不能捏造價格。實機畫面與 APK 安裝需驗收，不能以單元測試宣稱 RELEASE PASS。
