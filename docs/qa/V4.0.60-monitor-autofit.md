# V4.0.60 Monitor automatic font fit

Base V4.0.59 / 8199f695f9411c120c8ad733ee0306c47e8e5b9d.

Per-mode control in Monitor → global typography: automatic font fit, min/max font size and text row height. Existing settings default OFF; manual scales/weights remain saved. In automatic mode measured glyph widths and row height minus gaps/padding determine one font size for each row. Too-long text ellipsizes at the user minimum; minimum-height clipping is avoided by growing just enough vertically.

Preview uses hidden max-size glyph measurement plus visible layout width; native uses TextView Paint after layout. Both preserve independent color/weight/line-height settings. One native pre-draw listener is removed after fitting or when rebuilt/destroyed; no timer or quote-source change.

Validation covers normalization, per-mode persistence, actual toggle, measured callbacks, stale callback rejection, nonzero gap/padding, production native fit math and layout consumer with nested horizontal rows, hidden clock, listener cancellation and OFF/manual behavior. Physical-device typography and continued live reception remain Device Pending.
